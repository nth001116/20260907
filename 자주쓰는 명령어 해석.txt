1. 파일 및 디렉토리 관리 (기초)
ll: ls -l의 alias(별칭). 파일 상세 정보를 출력합니다.

ls -a: 숨김 파일을 포함한 모든 파일을 출력합니다.

ll -lt: 상세 정보를 시간순(최신순)으로 정렬하여 출력합니다.

ll -r: 상세 정보를 역순으로 정렬하여 출력합니다.

mkdir: 디렉토리를 생성합니다.

chmod: 파일이나 디렉토리의 권한을 변경합니다.

chown: 파일이나 디렉토리의 소유자/그룹을 변경합니다.

vi / vim: 리눅스의 기본 텍스트 편집기입니다. (vim은 vi의 확장 버전)

cp -rp: 파일/디렉토리를 복사하되, 권한 유지(-p) 및 하위 디렉토리 포함(-r)해서 복사합니다.

mv: 파일/디렉토리를 이동하거나 이름을 변경합니다.

rm -rf: 디렉토리와 그 내부의 모든 것을 묻지 않고 강제로 삭제합니다.

2. 프로세스 및 시스템 모니터링
ps -ef: 현재 실행 중인 모든 프로세스를 상세히 확인합니다.

tail -f: 로그 파일의 끝부분을 실시간으로 계속 출력합니다. (실시간 로그 모니터링용)

history: 내가 이전에 입력했던 명령어 기록을 확인합니다.

nload: 네트워크 트래픽 사용량을 실시간 그래프로 보여줍니다. (패키지 설치 필요)
-------------------------------------------------------------------------------
3. 네트워크 진단 및 설정
netstat -tupan: 현재 활성화된 네트워크 연결, 포트 상태, 프로세스를 확인합니다.

tcpdump -nni [인터페이스]: 특정 인터페이스의 패킷을 덤프(캡처)하여 분석합니다.

tcpdump -Anni [인터페이스]: 캡처한 패킷 내용을 ASCII(문자) 형태로 출력하여 보여줍니다.

nmcli: Network Manager CLI. 네트워크 연결 상태를 관리합니다.

nmcli dev status: 네트워크 장치들의 상태를 확인합니다.

nmcli con up/down <port>: 네트워크 인터페이스(연결)를 활성화/비활성화합니다.

nmcli con reload: 네트워크 설정 변경 사항을 다시 불러옵니다.

nmtui: 네트워크를 설정할 수 있는 사용자 친화적인 GUI 환경을 띄웁니다.
------------------------------------------------------------------------------------------
4. 권한 및 관리
su: 다른 사용자(주로 root)로 계정을 전환합니다.

sudo: 관리자(root) 권한으로 명령어를 실행합니다.

passwd: 현재 계정의 비밀번호를 변경합니다.
---------------------------------------------------------------------------------------------------
5. 서비스 및 압축 관리
systemctl status/start/stop ...: 서비스(데몬)의 상태 확인, 시작, 정지를 제어합니다.

tar -xvf: .tar 압축 파일을 해제합니다.

tar -cvf: 여러 파일이나 디렉토리를 하나의 .tar 파일로 묶습니다.

crontab -e: 주기적인 작업을 예약하는 스케줄러(cron) 파일을 수정합니다.

crontab -l: 현재 등록된 예약 작업 목록을 확인합니다.
------------------------------------------------------------------------------------------------------
6. 데이터 필터링 및 실행
| grep: 파이프(|)를 통해 앞선 명령어의 결과를 넘겨받아 특정 단어를 검색합니다.

grep -r: 디렉토리 내의 모든 파일에서 특정 문자열을 재귀적으로 검색합니다.

java -jar: 자바 기반의 실행 파일(.jar)을 실행합니다.
